# Carson Woodard: portfolio website

Source for https://cwoodard3950-cloud.github.io/, hosted on GitHub Pages.

- `index.html` is the whole site (HTML, CSS and JavaScript in one file). Pages use hash routes like `/#resume` and `/#haps`.
- `404.html`, `robots.txt`, `sitemap.xml` and `og.png` (the link preview image) support it.

## Updating the site

Edit `index.html`, then run:

```
git add -A && git commit -m "Update" && git push
```

The change goes live in about a minute.
